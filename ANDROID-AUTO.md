# Android Auto

Rude-Sat-Nav is built from an Organic Maps revision that includes Android Auto support.

The customisation is intended to preserve that existing integration.

## Using Android Auto

After installing the APK:

1. Connect the Android phone to the vehicle.
2. Start Android Auto.
3. Open the Android Auto app launcher.
4. Select Organic Maps / Rude-Sat-Nav.
5. Select a destination.
6. Start navigation.

The navigation interface displayed on the vehicle is provided by the Organic Maps Android Auto implementation.

## Voice instructions

Voice instructions are generated by the Android application and spoken using the Android system Text-to-Speech engine.

The rude commentary is added to the navigation text before it is passed to the TTS engine.
